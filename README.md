# License Lens · SBOM 准入门禁

纯前端软件物料清单（SBOM）准入证据链工具。每批记录包名、版本、来源摘要、渠道和用途；相同「包名 + 版本 + 来源摘要」只合并批次，不重复建证据。

## 门禁规则（命中即禁止放行，保留原批次并列出差异与规则）

1. **缺包内声明或人工核验** —— 组件须具备包内许可证声明或人工核验记录，两者皆缺时拦截。
2. **高风险未定责任人与期限** —— 高风险许可证组件必须同时指定责任人与整改期限。
3. **GPL 系用于闭源渠道** —— GPL / AGPL 等 Copyleft 组件不得进入闭源分发渠道。

## 证据链

- 放行后冻结证据快照与裁决，批次只读。
- 重检以来源批次为蓝本新建带原因的批次，旧批次保留可查。
- 数据持久化在 localStorage，刷新后非冻结批次按当前证据与规则重算，批次、变化和门禁保持一致。

## 分层

- `src/data/` —— 许可证知识库、种子数据（纯数据）
- `src/domain/` —— 数据模型、门禁规则（纯函数）、批次存储（合并 / 差异 / 冻结 / 持久化）
- `src/App.tsx` —— 界面层

## 运行

```bash
npm install
npm run dev
```

导入格式：每行 `name@version 许可证 | 来源摘要 | 渠道 | 用途`，`#` 开头为注释。
