# License Lens

纯前端 SBOM 准入证据链工具。打开 `index.html` 即可使用（无需构建、无外部依赖），数据保存在浏览器 localStorage。

## 功能

- **批次化准入**：每批记录包名、版本、来源摘要、渠道与用途；相同来源摘要只合并批次关联，不重复建档（见「组件台帐」）。
- **门禁规则**（任一触发即禁止放行）：
  - R1 证据齐备：缺包内声明或人工核验；
  - R2 高风险责任落实：高风险条目未定责任人与整改期限；
  - R3 GPL 系隔离闭源渠道：GPL / AGPL / LGPL 组件进入闭源分发渠道。
- **差异追踪**：每批保留相对基线批次的新增、移除与变更，并列出逐条规则裁决。
- **放行冻结**：放行后证据与裁决冻结，只读可查；重检必须填写原因并新建批次，旧批次保留可查。
- **一致性**：条目变更或点击「刷新门禁」后，批次、差异与门禁裁决同步重算。
- 支持粘贴/序列化导入、手动补录条目、导出 Markdown 准入报告。

## 结构（数据、规则、界面分离）

| 文件 | 职责 |
|---|---|
| `data.js` | 数据层：许可证知识库、渠道/用途字典、示例批次、状态与持久化 |
| `rules.js` | 规则层：三条门禁规则与批次差异计算（纯函数） |
| `ui.js` | 界面层：渲染与交互 |
| `license-lens.css` | 样式 |

## 导入格式

每行一个组件：`名称@版本 许可证 摘要 渠道 用途`（后三项可省略）。

- 渠道：`npm` / `mirror` / `vendor` / `commercial`（闭源）/ `embedded`（闭源）
- 用途：`runtime` / `dev` / `build` / `test` / `bundle`

重检时相同摘要的条目自动继承基线批次的证据字段（声明、核验、责任人、期限）。
